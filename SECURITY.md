# Security Policy

[Deutsch](SECURITY.de.md)

## Supported Versions

| Version | Supported |
| --- | --- |
| Current files on `main` | Yes |
| Older downloaded copies | No |

ChatGPT Pets is an asset collection rather than a versioned application, so support follows the current repository state.

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public GitHub issue. Contact the repository owner privately and identify the affected pet, file and import workflow. Do not include private ChatGPT or Codex conversation data in reports.

## Scope

Relevant reports include malformed or unexpected repository files, unsafe downloadable content, misleading file types, or content that behaves differently from the documented pet-import workflow. The repository does not require ChatGPT or Codex credentials, API keys or conversation exports.

Thank you for helping keep ChatGPT Pets safe to use.
