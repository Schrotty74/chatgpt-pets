# Security Policy

[Deutsch](SECURITY.de.md)

## Supported Content

Security reports are accepted for the current files published in this repository.

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public GitHub issue. Contact the repository owner privately and identify the affected pet, file and import workflow. Do not include private ChatGPT or Codex conversation data in reports.

## Scope

ChatGPT Pets distributes downloadable sprite-sheet assets and documentation for custom animated pets used with ChatGPT and Codex. Relevant reports include malformed or unexpected repository files, unsafe downloadable content, misleading file types, or content that behaves differently from the documented pet-import workflow.

The repository does not require users to provide ChatGPT or Codex credentials, API keys or conversation exports. A pet import should require only the intended downloaded pet asset and the import controls of the target application.

Thank you for helping keep ChatGPT Pets safe to use.
