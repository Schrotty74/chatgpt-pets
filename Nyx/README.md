# Nyx

[English version](README.en.md)

<img align="left" width="220" src="preview-transparent.png" alt="Nyx, ein schwarzer Roboter mit cyanfarbenen Augen und Fledermausflügeln">

Nyx ist ein kleiner schwarzer Roboter mit cyanfarbenen Augen und Fledermausflügeln. Er begleitet die Arbeit mit neun Animationen und schaut in 16 Richtungen.

<br clear="left">

## Installation

Den Ordner `Nyx` herunterladen und nach `~/.codex/pets/nyx` kopieren. Anschließend Nyx in Codex auswählen.

Zum Import über die Pet-Verwaltung die Datei [nyx-spritesheet.webp](nyx-spritesheet.webp) herunterladen. Das Sprite-Sheet liegt auch als [PNG](nyx-spritesheet.png) vor.
